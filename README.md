## The entry

Exactly one emoji — the one most likely to make a stranger smile:

😄

A big, genuine, open grin. Warm and friendly at first glance, readable the same way by a stranger of any age or background, and a step more chosen than the first default smiley that comes to mind — while staying instantly readable. No intimacy, sarcasm, or flirtation that would read oddly from someone unknown. Just unguarded delight.

## How it works

`main.py` (Python 3.13 standard library only) writes exactly that one emoji — and nothing else, no text, no trailing newline — to `/output/entry.txt`.

```sh
python3 main.py
```
